Project Overview
An interactive data analysis and visualization project based on the **Stack Overflow Developer Survey 2024**.

The project explores how developers use AI tools, their trust in AI-generated outputs, perceived productivity benefits, common challenges, and the relationships between AI adoption, professional experience, and salary.

Dataset
- **Source:** Stack Overflow Developer Survey 2024
- **Original dataset:** 65,437 respondents
- **Cleaned dataset:** 65,437 rows and 12 columns
- **Data file:** `cleaned_data.csv`

Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- Streamlit
- Jupyter Notebook

Project Components
- **EDA Notebook:** Data exploration, cleaning, visualizations, and insights.
- **Streamlit Dashboard:** Interactive charts, filters, developer comparisons, and key findings.
- **Cleaned Dataset:** Processed survey data used by the dashboard.

How to Run
1. Install the required libraries:

   `pip install -r requirements.txt`

2. Launch the dashboard:

   `streamlit run app.py`

Key Findings
- Approximately 62% of respondents who answered the AI adoption question reported using AI tools.
- Productivity improvement was the most commonly reported AI benefit (81% of respondents to the benefits question).
- High trust in AI-generated accuracy remains limited.
- AI adoption varies across developer roles and experience levels.
